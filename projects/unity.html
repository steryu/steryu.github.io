UNITY

A solo made hobby game project

A work in progress Roguelike themed game in Unity using C# scripting in order to learn the game engine Unity.

By designing this game and making it, relaying purely on code, I learn a lot of mechanics in order to implement the features I want. I mostly focused on data management since I want to add a lot of content seemingly along the way.

For now I have a solid base with inheritance to add enemies, abilities and character stats with ease.

GitHub readme page

Future Implements

I'm having so much fun coding this game. There are a lot of challenges but it's satisfying when you figure it out and it works, and when you see it in game it makes all the struggles worth it. I've got lots and lots of ideas, So I'm excited!

  • Loads of abilities and more enemies
  • Enemies that drop their respective items to then craft potions for buffs
  • To be able to merge skills for unique variations to keep every run fresh
  • A solid scaling system
