CPP MODULES

Fundamental steps into C++

This was our first step into C++. Using my knowledge of C, transitioning into the new language was not hard.

The goal of these modules is to introduce you to Object-Oriented Programming. There are in total ten CPP modules, each of which was crafted to learn specific subjects.


  • Module 0: The specifities of the language when compared to C
  • Module 1: Memory allocation, reference, pointers to members and switch statements
  • Module 2: Ad-hoc polymorphism, overloads and orthodox canonical classes
  • Module 3: Inheritance
  • Module 4: Subtype polymorphism, abstract classes and interfaces
  • Module 5: Try/Catch and Exceptions
  • Module 6: Different casts
  • Module 7: Templates
  • Module 8: Templated containers, iterators and algorithms
  • Module 9: Containers

Each of these modules gave me the essential and fundamental knowledge of that subject, which I now use in all my projects, including my hobby game project.
