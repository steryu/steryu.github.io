TRANSCENDENCE

This project is about creating a website for the mighty Pong contest!

This was a big group project at school to create a single-page web application with real-time chat functionality and a multiplayer pong game.


My main role in the project was to design the website and create the pong game using Typescript. It was my first time using NestJS and Vue but after I grasped the basics I managed to make a smooth working game. But the real challenge was to make it multiplayer and able to run multiple games simultaneously with different players connected to the same host.


In order to achieve this I instantiated and constructed a new game with all the necessities the game needed and send that to the connected players of that game using sockets in a constant loop. This ended up working great and with the rest of my team we managed to make a functional and nice looking website!

Tech Stack

TypeScript Docker Socket.io NestJs Prisma PostgreSQL Bcrypt Passport and JWT Vue PrimeVue Speakeasy and QR Code Axios
