SO LONG

A mini 2D maze game

This was my first graphical assignment at school.


The aim of this project was to gain familiarity with fundamental game development components such as textures, sprites, animations, and basic gameplay mechanics. The game was made in C and uses the MiniLibX library.


The goal of the game is to navigate the player through a maze using the W, A, S, D keys and collect all the collectibles throughout the map before reaching the exit.


The sprites are self made.



This project is only compilable on MacOs.
