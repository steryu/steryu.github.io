PANZERDOGS

PVP play & earn tank brawler game on Sui by lucky Kat Studios

Panzerdogs is a game created by Lucky Kat with a million downloads on iOS and Android where I currently work as the main Game Developer. I collaborate in a team with game designers and artists to create the best player experience possible.

Features I have built:

  • An invite system for friends using APIs
  • Exclusive partnership tanks with special VFX you can earn by winning tournaments
  • A helicopter with flying animations that drops you off at spawn
  • New tanks and a comprehensive tank upgrade system
  • Battle pass with new rewards every month

My primary role at Panzerdogs involves fixing bugs, optimizing existing code, conducting code reviews, and implementing new features using our custom JavaScript and Three.js-based game engine, Bento.

While developing these new systems, I'm ensuring that they seamlessly integrate with the existing code, to maintain a clean and scalable architecture.

At every challenge, assignment and feedback at LuckyKat I'm learning new things and techniques that help me grow as a game developer and software engineer where people can count on!

Tech Stack

Bento JavaScript Three.js NodeJs
