WEBSERV

This project is to make you write your own HTTP server

This is a project I worked on with 2 other teammates.

We made a web server from scratch in C++ that is able to use POST, GET and DELETE methods using Epoll. The server is fully useable in the browser.

The POST and DELETE method is demonstrated by being able to upload files and deleting those.


My job was to implement the main loop using Epoll and the CGI (common gateway interface). With CGI the webserver is able to execute any external python script.

The server is able to handle multiple clients at the same time.


Design made by Eva Lieve.
